# 🎯 クリフトンストレングス 177問診断ツール

クリフトンストレングスの34資質に基づいた177問の対比式診断テストをWebブラウザ上で実施し、ユーザー固有の強みプロフィールをリアルタイムで可視化するHTMLアプリケーションです。

**サーバーレス・シングルファイルで動作し、インストール不要で利用できます。**

---

## ✨ 主な特長

- **177問の対比式（バイポーラ）診断** — 2つの対照的な記述を1〜5のスケールで比較
- **34資質すべてを計測** — 各質問が2つの資質に同時にスコアを付与
- **回答後0.35秒で自動進行** — テンポよく直感的に答えられるUI
- **即時結果表示** — 診断完了後に全34資質ランキング・ドメイン別スコアを可視化
- **外部依存ゼロ** — サーバー不要、APIキー不要、オフラインでも動作
- **モバイル対応** — デスクトップ・タブレット・スマートフォン全対応

### 方法1：ブラウザで直接開く
1. `strengths_bipolar.html` をダウンロード
2. ファイルをブラウザにドラッグ＆ドロップ
3. または、ファイルをダブルクリック

### 方法2：ローカルサーバーで実行（オプション）

## 📋 画面構成（3タブ）

### 📖 34資質一覧タブ
- 34資質をドメイン別に一覧表示
- 各資質をクリックすると詳細説明と活用ヒントが展開
- 資質の説明文と3つの活用ヒントを確認可能

### 📝 177問診断タブ
- 対比式の177問に回答
- リアルタイムプログレスバーで進捗表示
- 回答後350ms自動進行
- 前後のナビゲーション機能付き
- 所要時間：約20～30分

### 📊 結果分析タブ
- 支配的ドメイン（最も高いドメイン）を表示
- 4つのドメイン別スコアをバーグラフで可視化
- 上位5資質の詳細情報カード
- 全34資質のランキング表

## 📊 スコアリング方式

### ポイント計算
回答値 `k`（1〜5）に対し、各資質へのポイント付与：

| ポジション | 計算式 | 1点 | 2点 | 3点 | 4点 | 5点 |
|-----------|--------|-----|-----|-----|-----|-----|
| **A側（左）** | `6 - k` | 5点 | 4点 | 3点 | 2点 | 1点 |
| **B側（右）** | `k` | 1点 | 2点 | 3点 | 4点 | 5点 |

### 正規化（0～100点）
```
最終スコア = (raw_scoreの合計) ÷ (登場問数 × 5) × 100
```

各資質は平均10～11問に登場し、十分な測定精度を確保しています。
